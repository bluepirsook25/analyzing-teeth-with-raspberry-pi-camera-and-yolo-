# YOLOv8 Pts

This project involves analyzing teeth using a Raspberry Pi and a camera, utilizing YOLOv8 Pts for real-time detection and analysis.

## Requirements

1. **Raspberry Pi 5 (2GB RAM)**
   - Minimum configuration recommended for optimal performance.
2. **Raspberry Pi Camera Module 3 or equivalent USB camera**
   - Ensure compatibility for accurate image capturing.
